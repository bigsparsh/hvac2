# Thermosync landing page

Vue 3 + Vite + Tailwind CSS implementation of the Thermosync landing page.

## Setup

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Structure

- `src/components/layout` — site header and footer
- `src/components/sections` — one component per page section
- `src/components/ui` — reusable buttons, cards, icons, table, section heading
- `src/data` — page copy and content
- `src/style.css` — Tailwind import, design tokens, fonts and small shared classes
